# MARS-CD：面向地理空间约束的倾斜无人机视频建筑物实例级变化监测

**Map-Anchored Relational Streaming Change Detection（当前版本 v3）**

> 推导过程、失败尝试与逐层迭代见 `research_iteration.md`；本文是面向 TGRS 投稿的方案描述。

---

## 摘要

现有遥感变化检测方法大多假设双时相影像像素对齐。这一假设在倾斜无人机视频中失效：投影带来的屋顶–足迹错位、视角差异、遮挡和消费级 GNSS 位姿误差相互叠加。我们提出 **MARS-CD**，一个以历史地理数据为锚的流式实例级变化检测框架。它把配准、跨视角/跨时相实例关联与变化判定统一为同一后验推断问题，并据此给出“变化 = 联合配准-关联问题的离群类”这一解释。框架包含五项核心机制：

1. **高度解耦的倾斜观测模型**：以与楼高无关的立面–地面接触线（GCL）完成影像空间“渲染–比较”配准与足迹约束，以逐实例一维高度扫描处理依赖高度的屋顶证据；
2. **层级空间关系推理（HSR）**：一阶外观 → 二阶空间关系保持（Lawler QAP，神经渐进指派 + SC² 二阶相容）→ 全局一致运动场 EM。其中全局项为内点/离群点对数似然比，dustbin 即新增/拆除后验；
3. **棱柱纹理图集（PTA）**：以建筑表面坐标索引的视角校正记忆，用于多视角证据累积与跨时相比较；
4. **证据式决策**：基于主观逻辑的意见，并以图集新颖度为相关视频帧做有效样本量折扣，区分“拆除”与“未观测”；
5. **非对称离线/在线范式**：T1 多源数据离线编码为地理锚定记忆，T2 视频在单卡上流式处理。

## 1. 问题定义

输入：T1 = {SHP 足迹（仅轮廓）、栅格地图、卫星/航摄 DOM、历史倾斜视频}；T2 = 当前倾斜视频 + 消费级 GNSS/云台角。
输出：地理坐标下的实例级变化集合
$\mathcal{C}=\{(j,i,c)\}$，$c\in\{\text{未变},\text{扩张},\text{收缩}\}$（匹配对），$(j,\varnothing,\text{拆除}/\text{未观测})$，$(\varnothing,i,\text{新增})$，附足迹多边形、置信度与主观逻辑意见 $(b,d,u)$，可回写 SHP。
约束：单卡 RTX 4090/3090，1080p，≥10 FPS 流式。

## 3. 方法：MARS-CD v3

### 3.1 后验分解（设计原则）

$$
p(\mathcal{T},X^2,\sigma\mid\mathcal{Z},\mathcal{G},X^1)\propto\prod_t p(I_t\mid X^2,T_t)\,p(\mathcal{T}\mid\mathcal{G})\,p(X^2\mid X^1,\sigma)\,p(\sigma)
$$

各因子分别由 CARR、结构头 + PASID、RRD、RIGM + HSR 近似推断，流式交替（变化信念 ↔ 配准权重）构成“流式变分 EM”。

### 3.2 模块

| 模块 | 关键机制 | 文件 |
|---|---|---|
| A 多源地理先验（离线） | 模态专属 stem + 共享主干 + 逐像元可靠性门控融合 + 模态 dropout；SHP token（形状 + 内部/环带上下文）；SHP 边界软栅格；T1 图集与 T1 高度后验 | `ortho_encoder.py` |
| B 倾斜编码器 | 轻量 FPN（部署：DINOv3 ConvNeXt-T/ViT-S 蒸馏） | `oblique_backbone.py` |
| v2-I 结构头 | 步长 4 的 GCL/屋顶边图；标签自动渲染；高度扫描；contact snake | `structure.py` |
| C CARR | 偏置 Kalman 先验 → BEV 特征相关 + **影像空间 GCL↔SHP 渲染比较** → 贝叶斯后验体 → 局部 soft-argmax → 特征度量 LM（带接受/拒绝与自适应阻尼）；变化区域排除 | `registration.py` |
| D PASID | 先验/跟踪/发现三类棱柱查询；地理关系自注意力；**竖直角线可变形采样**；图集记忆注意力；层级（实例 + 顶点）迭代精化 + contact snake；状态 LayerNorm | `prism_decoder.py` |
| v2-III PTA | 表面参数化图集、可见性/朝向/斜视权重、共视比较 + 新墙/丢失墙证据、场景级归一化 | `atlas.py` |
| E RIGM | 姿态无关节点特征、刚体不变关系嵌入、不确定性归一的跨图偏置、节点自适应 dustbin | `graph_matcher.py` |
| v2-II HSR | 几何 kNN ∪ 一元 top-k 候选；学习的二阶兼容 + SC²；√deg 归一的 GA；留一法运动场 EM 的对数似然比 | `relational_assignment.py` |
| F 变化推理 | 留一法局部刚体 ICP-Procrustes（RRD）+ 双向符号距离 + 图集比较 + 有界面积证据 | `change_head.py` |
| v3 证据决策 | 可观测度 × 新颖度加权的 Beta 证据；$u<u_{max}$ 才判拆除 | `evidential.py` |

### 3.3 关键公式（详细推导见 `research_iteration.md`）

* 屋顶 IPM 错位：$\Delta=rh/(H-h)$；接地线在 $z=z_g$ 上可精确逆映射。
* 结构似然：$s(\alpha,\delta)=\frac{1}{|\mathcal{P}|}\sum_{X\in\mathcal{P}}\sigma\big(\mathrm{GCL}(\pi(G_{\alpha,\delta}^{-1}(X);T_{prior}))\big)$，$\mathcal{P}$ 为面向相机的 SHP 边界点。
* HSR：$Q_m=s_m+\lambda\frac{(C^{(2)}P)_m}{\sqrt{\deg_m}}+\kappa-\frac{e_m^2}{2\sigma_g^2}$，$P=\mathrm{Sinkhorn}_\beta(Q;\alpha,\beta)$，dustbin = 出生/死亡。
* PTA 权重：$w=\mathbb{1}_{img}\mathbb{1}_{facing}\mathbb{1}_{vis}\cos\angle(\mathbf{v},\mathbf{n})$。
* 证据：$r\mathrel{+}=o\,\nu\,\mathrm{softplus}(\ell)$，$s\mathrel{+}=o\,\nu\,\mathrm{softplus}(-\ell)$，$\nu=\frac{\sum\Delta W_c/(1+W_c)}{\sum\Delta W_c}$，$u=\frac{2}{r+s+2}$。

## 4. 训练

**标签体系**：T2 建筑足迹多边形（地理坐标）+ 与 T1 SHP ID 的对应表 + 变化类别；逐帧真值位姿由离线空三获得（需确认）；高度伪标签来自摄影测量 DSM；GCL/屋顶边/可见性/占用标签全部由几何自动渲染。

**损失**：配准（后验 NLL + 位姿）、结构图 focal、存在性 focal、置换等价多边形 L1 + 边方向、高度/基底、发现热图、帧内关联 OT、跨时相关联 OT（HSR + 一元深监督）、变化 CE、证据 Beta 损失、SHP 一致性辅助损失。

**课程**：① CARR 预训练（GT 位姿 + 模拟消费级 GNSS 偏置随机游走/航向偏置/时间戳偏移）；② PASID 位姿教师强制（概率 1→0.3）；③ HSR/变化推理（SHP 编辑合成变化增广）；④ 片段级端到端微调（截断 BPTT，图集片段内可微）。
**预训练数据**：BONAI/OmniCity（离底偏移）、UrbanBIS/UrbanScene3D（倾斜建筑）、University-1652/UAV-VisLoc/PiLoT 数据（跨视角配准）、FOTBCD/LEVIR-CD（正射分支）、MatrixCity 等合成城市（可控变化）。

## 5. 实时性（RTX 4090，FP16/TensorRT，960×544 输入，自 30 FPS 中每 3 帧处理 1 帧）

| 环节 | 估计耗时 | 说明 |
|---|---|---|
| 解码 + 缩放 | ~1 ms | NVDEC |
| 骨干 + FPN | 5–8 ms | ConvNeXt-T 级 |
| 结构头（步长 4） | 1–2 ms | v2-I 分辨率约束要求步长 4 |
| CARR | 3–4 ms | 9 yaw × 25² 偏移相关 + 结构体 2601 假设 × ≤4096 点 + 3 次 LM |
| 高度扫描 + PASID | 4–6 ms | ≤150 实例 × 16 顶点 × 3 层 |
| z-buffer + 图集 + 证据 | 1–2 ms | scatter 操作 |
| 帧内关联 | 1–2 ms | 空间门控 |
| **合计** | **≈16–25 ms/帧** | 预计 40–60 FPS 理论上限，满足 ≥10 FPS |
| 跨时相 HSR（周期性） | 数 ms–数十 ms | 每秒或每航段执行，不计入逐帧；留一法刚体场以充分统计量核回归实现，O(P²) |

以上为估算，需在 4090 上用 `tools/benchmark_latency.py --config deploy --half` 实测。

## 7. 合成数据端到端训练（冒烟）

CPU、tiny 配置（1.12 M 参数）、256×160 输入、6 个训练场景 × 60 次迭代（约 170 s），留出场景评估。**仅验证可训练性，不代表精度**：

| 损失项 | 前 10 次均值 | 后 10 次均值 |
|---|---|---|
| 总损失 | 14.23 | 12.84 |
| 结构图（GCL/屋顶边） | 1.15 | 0.57 |
| 跨时相关联（HSR + 一元） | 1.60 | 1.29 |
| 变化分类 | 0.84 | 0.74 |
| 证据 Beta 损失 | 0.46 | 0.40 |
| 存在性 | 0.13 | 0.04 |
| 发现热图 | 1.63 | 1.08 |
| 配准后验 NLL | 7.15 | 8.18（未下降） |

留出场景：T1 侧决策准确率 0.61，T2 足迹 mIoU 0.76；本次运行没有预测出“新增”（新增的 P/R 为 0）。配准：BEV 粗配准 4.68 m（先验 5.13 m），但 LM 精化后为 5.61 m，**劣于先验**。
如实说明：① 配准分支在联合短训练中不收敛，需要按课程先做 CARR 的独立预训练；② 256×160 低于 §6 中 GCL 的分辨率下限，结构通道在此设置下无法分辨米级误差；③ LM 的接受/拒绝规则只能保证特征度量代价不上升，在未训练的特征上不能保证位姿改善。

## 8. 实验设计

**指标**：
* 实例级变化：各类 P/R/F1（地理坐标、足迹 IoU ≥ 0.5），mF1；**误报拆除率**；“未观测”弃权率（abstention）；
* 关联：T1↔T2 匹配精度/召回，帧内 IDS、HOTA/AssA；
* 足迹几何：IoU、PoLiS、边界 F@1 m；
* 配准：中位/90% 位置误差、航向误差、成功率（<1 m 且 <1°）；
* 效率：FPS、逐模块时延、显存、参数量。

**基线**：
* B1 离线正射路线：T2 SfM 正射 + ChangeMamba/Change3D/BCE-Net（非实时精度参照）；
* B2 帧级实例分割（SAM 3/Mask2Former）+ LOFT/OBMv2 偏移 + IPM + 匈牙利 IoU 关联 + 规则；
* B3 StreamVGGT / VGGT-SLAM 2.0 重建 + 足迹提取 + 规则匹配；
* B4 O-SCD（CVPR'26）像素级在线变化 → 实例聚合。

**消融**：GCL 渲染比较 vs BEV 抬升 vs 无结构通道；高度扫描 vs 回归；HSR 各层（一元 / +二阶 / +全局 LLR）、候选生成方式、归一化方式；PTA vs 视角槽记忆；图集比较特征与场景归一化；证据决策 vs noisy-or；新颖度折扣；各 T1 数据源贡献；查询类型；记忆大小与 FPS 的权衡。
**鲁棒性曲线**：GNSS 偏置 0–10 m / 0–8°、模态缺失、帧率、航高/俯仰角、两期光照差异。

## 9. 创新点（对标 TGRS）

1. **问题层面**：首次把倾斜视频建筑变化监测形式化为“配准-关联-变化”联合后验，给出“变化 = 离群类”的统一解释，并实现端到端流式实例级框架。
2. **高度解耦观测模型（v2-I）**：给出接地线高度不变性的几何推导与定量误差界；在影像空间完成渲染比较配准，避免 BEV 抬升的各向异性模糊；配合逐实例高度扫描。
3. **层级空间关系推理（v2-II）**：一阶 → 二阶 QAP → 全局运动场 EM；全局项采用内点/离群点对数似然比，在外观不可区分的建筑群上把关联准确率从 19% 提升到 99%。
4. **棱柱纹理图集（v2-III）+ 证据式决策（v3）**：视角校正的表面记忆，给出几何化的扩张/收缩证据；基于主观逻辑和有效样本量折扣，严格区分“拆除”与“未观测”。

| 质疑 | 回应 |
|---|---|
| 为何不直接用 VGGT 类前馈重建？ | 计算量与实时约束；缺绝对地理坐标；作为离线教师与基线 B3 对比 |
